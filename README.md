## Features
- User Deactivation: Uses Supabase’s native JWT to ensure strong encryption and advanced security.
- Complex Reports: Processes and validates requests to generate PDF and Excel reports with Pandas and FPDF, including user access control and error handling.

## How to Run

### Run Locally
1. Clone the repository:
```bash
   git clone https://github.com/youruser/solicitacoes_api.git
   cd solicitacoes_api
```

2. Create and activate a virtual environment:
```bash
   python -m venv venv
   source venv/bin/activate   # Linux/Mac
   venv\Scripts\activate      # Windows
```

3. Install dependencies:
```bash
   pip install -r requirements.txt
```

4. Set environment variables:
```env
   SUPABASE_URL=...
   SUPABASE_SECRET_KEY=...
   SUPABASE_JWKS_URL=...
```

5. Run the API:
```bash
   uvicorn main:app --host 0.0.0.0 --port 10000
```

The API will be available at: http://127.0.0.1:8000

---

### Deploy on Render
1. Create a new Web Service on Render.
2. Point it to this repository.
3. Set the Build Command:
   pip install -r requirements.txt
4. Set the Start Command:
   uvicorn main:app --host 0.0.0.0 --port 10000
5. Define environment variables (SUPABASE_URL, SUPABASE_KEY, JWT_SECRET) in the Render dashboard.
6. After deployment, the API will be accessible via the URL generated by Render.
